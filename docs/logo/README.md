# Huginn Downloader logo

The raven mark is a 1024x1024 transparent crop of the maintainer-supplied
generated artwork. The crop removes half of the original red margin around the
raven; the SVG, WebP, and AVIF files share that framing.

| File | Purpose |
| --- | --- |
| `huginn-logo.svg` | Layered vector master with a transparent background. |
| `huginn-logo.webp` | Lossless transparent WebP for GitHub and other web use. |
| `huginn-logo.avif` | Lossless transparent AVIF for archival. |

`extension/icons/plugin.svg` is a separate 32x32 toolbar treatment: a white
raven silhouette on the Huginn red rounded square, so the mark stays legible at
Firefox toolbar sizes and against both light and dark browser themes.
