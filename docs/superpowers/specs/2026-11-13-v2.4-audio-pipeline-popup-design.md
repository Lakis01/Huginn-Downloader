# Firefox YouTube Downloader Plugin v2.4 — Audio Pipeline & Popup Design

## Intent

Refine the local download pipeline and Firefox popup without changing the YouTube watch-page pill. Provide clear codec/container choices, an optional per-download stereo/mono decision, optional thumbnail embedding and legacy JPEG conversion, optional duration-based routing, and a compact, polished popup. Retire the obsolete Tampermonkey, External Application Launcher, and `yt-dlp://` launch pathway from the current source and public docs.

## Product Decisions

- **Audio output format:** `best` (native Opus/M4A, no audio re-encode) is the default; `opus` and `m4a` force those containers and transcode only when the selected native stream does not match; `mp3`, `ogg`, and `flac` use FFmpeg conversion.
- **MP3 quality:** `V0` is the default; supported options are `V0`, `320k` CBR, `V2`, and `V5` VBR. Legacy saved value `128k` migrates to `V5`.
- **Channels:** `stereo` is the default; optional `ask` prompts per audio/cut download for stereo vs. mono; `mono` always downmixes. Mono is a download-level config setting, not another watch-page button.
- **Cut behavior:** `Cut Audio` follows the selected output format; when `best` or `opus` is selected, defaults to Opus 128 kbps VBR stereo (75 kbps VBR mono). MP3 follows configured MP3 quality. User can still adjust the per-cut bitrate, channels, and Opus application.
- **Thumbnail:** embedding is on by default. `thumbnail_jpg` is off by default; when on, convert cover art to JPEG for legacy hardware, otherwise preserve/use WebP for Opus/Ogg/MP3/FLAC and JPEG for M4A/MP4.
- **Long-audio routing:** off by default. When enabled, a completed audio file (or selected cut's actual segment duration) at or above 30 minutes moves into a separately configured folder (`~/Podcasts` default, `~/Audiobooks` preset, or custom path), regardless of whether tagging is enabled.
- **Extension popup:** replace the tall stacked settings card with a compact, approachable toolbar panel. Codec and MP3 quality first, channel choice directly below, concise toggles, one download-folder dropdown, optional long-audio fields revealed only when enabled. No `(on/off by default)` label suffixes. Keep the watch-page pill untouched.
- **Context menu:** clear persisted stale Firefox menu definitions with `menus.removeAll()` before recreating. Omit URL patterns so right-click remains available over `about:blank` autoplay frames, `blob:` previews, images, and links; Native Messaging accepts safe HTTP(S) sites supported by yt-dlp.
- **Legacy integration removal:** no Tampermonkey or External Application Launcher code, docs, fixtures, or custom URI-handler integration remains in the published source. Preserve the unrelated Play in MPV integration.
- **Licensing:** MIT license.

## Safety & Compatibility Constraints

- Never modify `~/.config/yt-dlp/config` or Firefox profile databases.
- Preserve metadata parsing/`yt-to-forerunner` compatibility and language-tag stripping in Opus, Ogg, FLAC, MP3, and M4A/MP4.
- Do not overwrite existing files when routing long audio; use collision-safe numbered suffixes.
- The long-audio duration decision must work when `auto_tag=false`; obtain duration from yt-dlp output/info data without performing an additional network extraction.
- The native host validates URLs and passes them as separate process arguments; no shell evaluation.
- Keep AMO API secrets out of logs and test fixtures; signing occurs after merged changes pass tests.
- Include the user's two provided screenshots (`watch-page-pill.png`, `context-menu.png`) in README; do not fabricate popup/shortcut screenshots.
