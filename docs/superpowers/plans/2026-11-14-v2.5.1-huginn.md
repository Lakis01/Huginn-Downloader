# Huginn Downloader v2.5.1 Implementation Plan

> **For agentic workers:** Use the executing-plans skill to implement the approved design task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Deliver Huginn Downloader 2.5.1 with external-binary-aware Linux setup, localized download folders, a non-blocking `yt-dlp` warning, faster opt-out tagging, and a compatible raven-brand refresh.

**Architecture:** Keep the current Python Native Messaging host and Firefox extension architecture. Resolve user directories through XDG on Linux, inspect dependencies before apt operations, preserve v2.5.0's extension/host/package/config identities, and change the user-facing brand plus release artifact names.

**Tech Stack:** Python 3, Bash, Firefox WebExtension, yt-dlp, FFmpeg, Debian/Fedora/Arch package metadata, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-14-v2.5.1-huginn-design.md`.

## Global Constraints

- Extension and Native Messaging versions become `2.5.1`.
- Visible name is `Huginn Downloader`; repository slug is `Huginn-Downloader`; icon is a raven.
- Keep Gecko ID `firefox-youtube-downloader@lakis01.github.io`, host ID `firefox_youtube_downloader`, package IDs, config paths, and installed system directories stable.
- Debian `Depends: python3`; `Suggests: yt-dlp, ffmpeg, python3-mutagen, python3-pil, rsgain`. Fedora `Requires: python3`; `Suggests: yt-dlp, ffmpeg-free, python3-mutagen, python3-pillow, rsgain`. Arch `depends=('python')`; `optdepends=('yt-dlp' 'ffmpeg' 'python-mutagen' 'python-pillow' 'rsgain')`.
- Apt helper checks `yt-dlp`, `ffmpeg`, `ffprobe`, `python3`, Mutagen, Pillow, and optional rsgain; install only missing items and skip apt-get update/sudo when none is missing. The `.deb` installs this helper at `/usr/lib/firefox-youtube-downloader/install-apt-deps.sh`.
- Linux defaults resolve XDG Music/Videos/Downloads with precedence env → `user-dirs.dirs` → English fallback; parse `$HOME` without shell evaluation. Migrate only the three known old default paths; preserve them if they contain any entry, including hidden files; custom paths remain unchanged.
- Branded release asset basenames: `huginn-signed.xpi`, `huginn-companion_2.5.1_all.deb`, `huginn-companion-2.5.1-1.noarch.rpm`, `huginn-downloader-2.5.1-source.tar.gz`, `huginn-downloader-2.5.1-arch-pkgbuild.tar.gz`. Package metadata IDs remain legacy for upgrades.
- Download attempts continue even when `yt-dlp` is marked outdated.
- Preserve automatic tagging behavior unless the user turns it off before post-processing; do not make `tags.json` an additional metadata source in this release.
- Do not read AMO key values, write them to disk, sign, tag, or publish until the package preflight on merged `main` passes.

## Review Focus

1. A curl-installed `~/.local/bin/yt-dlp` is found by Firefox and is not replaced by apt's older package.
2. The apt helper skips each detected command/module, omits apt-get update when nothing is missing, and keeps rsgain optional.
3. XDG paths from environment or `user-dirs.dirs` resolve correctly; custom paths and populated legacy folders are retained.
4. An outdated cached version warns but does not prevent an attempted download; failed downloads say the version may have contributed.
5. Turning auto-tag off during download skips tagging and cleans generated tag/thumbnail sidecars; sources with no title/artist/album/date/credits and no cover skip media copying, while ordinary title/channel fallback tagging remains enabled.
6. Firefox add-on ID, host ID, config locations, package IDs, and filesystem paths remain stable across the visible Huginn rename.
