# Firefox YouTube Downloader Plugin v2.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.4 with native/forced audio formats, optional mono-per-download, thumbnails, duration-based folder routing, a compact redesigned popup, a persistent always-available context menu, legacy-integration removal, and current MIT/screenshot documentation.

**Architecture:** `ytdl_config.py` owns validated settings and backward-compatible migrations. The wrapper selects a codec without needless re-encoding, requests duration in the same yt-dlp pass, asks for channels only in `ask` mode, embeds/routs final audio safely, and keeps rsgain after final placement. The popup offers compact controls that map directly to config. The background recreates menus after clearing persisted definitions and the native host accepts any safe HTTP(S) yt-dlp target. Documentation presents the extension as a local two-part system, not a previous-integration migration.

**Tech Stack:** Python 3, Bash, JavaScript/Firefox WebExtension, yt-dlp, FFmpeg, Mutagen, Pillow, optional rsgain, Mozilla AMO `web-ext` signing.

**Spec:** `docs/superpowers/specs/2026-11-13-v2.4-audio-pipeline-popup-design.md`.

## Global Constraints

- Never create, modify, or overwrite `~/.config/yt-dlp/config`.
- Never modify Firefox profile databases.
- Keep `audio_format: "best"`, `mp3_quality: "V0"`, `channel_mode: "stereo"`, `embed_thumbnail: true`, `thumbnail_jpg: false`, `mono_audio: false` (legacy migration only), `long_audio_enabled: false`, `long_audio_minutes: 30`, `long_audio_dir: "~/Podcasts"` as defaults.
- Legacy MP3 quality `"128k"` loads/saves as `"V5"` (`-V 5`) rather than a CBR 128k preset.
- `best` preserves native Opus or M4A when stereo; forced `opus`/`m4a` transcode only when the selected native codec differs; `Cut Audio` follows chosen format and defaults to Opus 128 kbps VBR stereo (75 kbps mono).
- For audio formats that can carry it (`.opus`, `.ogg`, `.mp3`, `.flac`), native WebP is preserved/embedded when `thumbnail_jpg=false`; legacy JPEG mode converts/embeds JPEG.
- Never leave Tampermonkey or External Application Launcher components/docs/tests or custom URI-handler code in the published source.
- Browser contexts must work through inline hover-autoplay, video/blob/image contexts, and external safe HTTP(S) media URLs; no URL/document pattern filtering or `onShown` dynamic gating.
- Never print AMO API credentials.

## Review Focus

1. **Backward-compatible config migrations:** v2.3 configs with `mono_audio` or `mp3_quality: "128k"` load to `channel_mode` and `V5` without losing existing values (Task 1 test).
2. **`auto_tag=false` + duration routing:** routing uses same-pass `after_move:duration` and avoids network re-extraction; existing destination names receive safe numbered suffixes (Task 1 tests).
3. **`channel_mode=ask` when noninteractive:** ask mode defaults safely to stereo on non-TTY instead of hanging (Task 1 test).
4. **Persisted Firefox menu migration:** stale old menu definitions are removed before new broad-context menus are created, with no URL-pattern gating (Task 2 test).
5. **No legacy integrations in published tree:** repository searches find no `Tampermonkey`, `External Application Launcher`, or `yt-dlp://` references in the current tracked source/docs after obsolete files are removed (Task 3 verification).

- `load_config()` migrates legacy `mono_audio: true` to `channel_mode: "mono"`, otherwise to `"stereo"`; legacy `mp3_quality: "128k"` maps to `"V5"`.

- `_audio_format_args(config)` supports native `best`, forced `opus`, forced/native-first `m4a`, `mp3` V0/320k/V2/V5, Ogg Vorbis, FLAC; forced mono adds `-ac 1` and rational bitrate.

- Audio/cut only download thumbnails when `embed_thumbnail=true`; `thumbnail_jpg=true` uses `--convert-thumbnails jpg`; otherwise retain native WebP.
- Native host `download` URL validation becomes safe generic HTTP(S), retaining mode validation, domain/port/userinfo/control-character checks.
